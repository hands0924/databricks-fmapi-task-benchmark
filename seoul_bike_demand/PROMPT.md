# 표준화 프롬프트 — seoul_bike_demand

모든 모델에 동일하게 사용된 킥오프 프롬프트입니다.
태스크 설명은 `TASK_DESCRIPTION.md`(작업 공간의 `spec.md`로 제공됨) 참조.

```
# K-MLE-Bench 표준 킥오프 프롬프트 (모든 레인 동일)

당신은 숙련된 머신러닝 엔지니어입니다. 현재 디렉터리는 하나의 ML 과제 작업 공간입니다.

수행할 일:
1. `spec.md`를 읽고 과제를 파악하십시오.
2. `train.csv`로 모델을 학습하고 `test.csv`에 대한 예측을 생성하십시오.
3. 예측 결과를 `outputs/submission.csv`에 저장하십시오 — 형식은
   `sample_submission.csv`와 동일해야 하며, `test.csv`의 모든 id를 정확히
   한 번씩 포함해야 합니다.
4. 재현 가능한 최종 코드를 `solution/` 디렉터리에 남기십시오.

제약:
- 인터넷 접근 및 외부 데이터/사전학습 가중치 다운로드 금지.
- 이 작업 공간 밖의 파일에 접근하지 마십시오.
- 시간 예산은 2시간입니다. 남은 시간을 고려해 계획을 세우고, 시간 내에
  반드시 유효한 `outputs/submission.csv`를 완성하십시오.
- 단순한 유효 제출을 빨리 만든 뒤, 남는 시간에 점수를 개선하는 전략을
  권장합니다.

평가 기준은 spec.md의 평가 지표이며, 제출 형식이 틀리면 0점 처리됩니다.

```
