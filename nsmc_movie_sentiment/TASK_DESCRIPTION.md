# 네이버 영화리뷰 감성 분석 (t4_nsmc)

## 배경
네이버 영화 리뷰 문장의 감성(긍정/부정)을 분류하는 과제입니다. 구어체, 축약어,
오타, 이모티콘이 섞인 실제 한국어 사용자 텍스트를 다루는 능력을 평가합니다.

## 데이터
- `train.csv` — 컬럼: `id`, `document`(리뷰 텍스트), `label`(0=부정, 1=긍정)
- `test.csv` — 컬럼: `id`, `document` (레이블 없음)
- `sample_submission.csv` — 제출 형식 예시

## 목표
`test.csv`의 각 리뷰에 대해 감성 레이블(0 또는 1)을 예측하십시오.

## 평가 지표
**Accuracy** (정확도). 높을수록 좋습니다.

## 제출 형식
`outputs/submission.csv` — 헤더 포함, 컬럼 2개:
```
id,label
6270596,1
9509303,0
```
- `test.csv`의 모든 `id`가 정확히 한 번씩 포함되어야 합니다.
- `label`은 0 또는 1이어야 합니다.

## 규칙
- 외부 데이터 및 사전학습 자료의 추가 다운로드 금지. 인터넷 사용 금지.
- 제공된 `train.csv`만을 학습에 사용하십시오.
- 시간 예산: 2시간. 재현 가능한 코드를 `solution/` 아래에 남기십시오.
