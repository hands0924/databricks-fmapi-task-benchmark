# 뉴스 토픽 분류 (t3_ynat)

## 배경
연합뉴스 기사 제목을 보고 해당 기사의 주제 분야를 분류하는 과제입니다. 한국어 뉴스
제목은 짧고 압축적이어서, 제한된 문맥에서 주제를 판별하는 모델링 능력이 필요합니다.

## 데이터
- `train.csv` — 컬럼: `id`, `title`(기사 제목), `label`(주제 분야)
- `test.csv` — 컬럼: `id`, `title` (레이블 없음)
- `sample_submission.csv` — 제출 형식 예시

레이블은 다음 7개 중 하나입니다:
`IT과학`, `경제`, `사회`, `생활문화`, `세계`, `스포츠`, `정치`

## 목표
`test.csv`의 각 제목에 대해 주제 분야를 예측하십시오.

## 평가 지표
**Macro F1** (7개 클래스에 대한 F1 점수의 단순 평균). 높을수록 좋습니다.

## 제출 형식
`outputs/submission.csv` — 헤더 포함, 컬럼 2개:
```
id,label
ynat-v1_train_00007,정치
ynat-v1_train_00013,스포츠
```
- `test.csv`의 모든 `id`가 정확히 한 번씩 포함되어야 합니다.
- `label` 값은 위 7개 클래스명 중 하나여야 합니다 (그 외 값은 무효 처리).

## 규칙
- 외부 데이터 및 사전학습 자료의 추가 다운로드 금지. 인터넷 사용 금지.
- 제공된 `train.csv`만을 학습에 사용하십시오.
- 시간 예산: 2시간. 재현 가능한 코드를 `solution/` 아래에 남기십시오.
